## LIVRABLE 3 — GUIDE D'ENTRETIEN (5 phases)

```
## 📋 Guide d'Entretien

### Phase 1 · Mise en confiance (5 min)

Script d'ouverture :
"Bonjour [prénom], merci de prendre ce temps. Je m'appelle [nom], je fais de la
recherche utilisateur — mon rôle c'est de comprendre votre expérience, pas de
tester un produit. Il n'y a pas de bonnes ou mauvaises réponses. Est-ce que ça
vous convient si je prends des notes ? [accord enregistrement si applicable]"

Question d'entrée :
"Pour commencer, est-ce que vous pouvez me raconter une journée type dans votre
travail / usage de [domaine] ?"

### Phase 2 · Contexte d'usage (8-10 min)

[3-4 questions sur l'environnement et les habitudes — SANS mentionner de fonctionnalité]

1. [question ouverte sur le contexte]
2. [question ouverte sur les habitudes]
3. [question ouverte sur l'apprentissage / adaptation]
4. [question sur les outils utilisés en parallèle]

### Phase 3 · Exploration profonde (15-20 min)

[5-7 questions spécifiques au contexte fourni]
Pour chaque question : 2 relances non-directives

**Q1** : [question]
  → Relance 1 : "Vous pouvez me donner un exemple concret ?"
  → Relance 2 : "Qu'est-ce qui s'est passé ensuite ?"

[répéter pour Q2 à Q7]

**Relances INTERDITES pour ce contexte** :
- "Est-ce que vous préféreriez si... ?"
- "Trouvez-vous que... ?" (orientée)
- [relances spécifiques à éviter selon le sujet]

### Phase 4 · Projection (5 min)

1. "Si vous pouviez changer une seule chose dans [domaine], ce serait quoi ?"
2. "À quoi ressemblerait pour vous une situation idéale ?"
3. "Qu'est-ce qui vous manque le plus aujourd'hui ?"

### Phase 5 · Clôture (3 min)

"Si vous deviez résumer cette conversation en une phrase, ce serait quoi ?"
"Est-ce qu'il y a quelque chose qu'on n'a pas abordé et qui vous semble important ?"
"Merci beaucoup — voici les prochaines étapes : [...]"
```

## LIVRABLE 4 — CHECKLIST PRÉ-ENTRETIEN

```
## ✅ Checklist Pré-Entretien

**Technique**
- [ ] Guide ouvert sur écran secondaire ou imprimé
- [ ] Teams/Zoom : tester micro et caméra 5 min avant
- [ ] Enregistrement cloud activé si accord écrit obtenu
- [ ] Transcription automatique activée si disponible
- [ ] Partage d'écran testé (si démo prévue)
- [ ] Notifications coupées (mail, Slack, Teams, téléphone)
- [ ] Timer visible

**Posture**
- [ ] Je ne vends rien, je ne défends rien, je ne juge rien
- [ ] Les silences sont mes alliés — attendre 3-5 sec avant relancer
- [ ] Éviter "pourquoi" → préférer "qu'est-ce qui vous a amené à..."
- [ ] Ne pas hocher la tête en signe d'approbation
- [ ] Note le verbatim exact entre guillemets, pas mon interprétation
```

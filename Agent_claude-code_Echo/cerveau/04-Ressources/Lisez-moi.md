# Ressources

Ce que la cellule mobilise sans l'avoir produit : méthodes, biais connus,
grilles d'analyse, benchmarks, lectures de référence.

**Différence avec `03-Connaissances/`** — une ressource est un savoir importé
(« le biais de désirabilité sociale existe »). Une connaissance est un savoir
que la cellule a produit sur **son** produit et **ses** utilisateurs
(« nos utilisateurs ne distinguent pas les paliers »).

Ne mélange pas les deux : une ressource n'a pas de niveau de confiance ni de
sources internes, une connaissance en a toujours.

## Rangement suggéré

```
04-Ressources/
├── Methodes/          protocoles, guides d'animation, échelles
├── Biais/             biais cognitifs et biais d'enquête
└── Benchmarks/        analyses concurrentielles, états de l'art
```

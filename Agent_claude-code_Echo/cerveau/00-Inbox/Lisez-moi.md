# Inbox

Tout ce qui arrive et n'a pas encore de place définitive atterrit ici :
une remarque en réunion, un lien, une observation de couloir, un export
à traiter.

**Règle** : capturer d'abord, ranger ensuite. Ne jamais bloquer une capture
parce qu'on ne sait pas où la classer.

ECHO vide l'Inbox à chaque session : chaque note rejoint un projet, un
domaine, une connaissance ou une ressource.

> Une Inbox qui grossit est le signe que le système se grippe. ECHO doit
> le signaler au pilote.

# Plan de recherche · Eclipse

Mode retenu : **mixed** — le questionnaire qualifie les participants,
les entretiens creusent ce que les chiffres ne disent pas.

## Séquence

| Jalon | Date |
|---|---|
| Questionnaire prêt | 2026-04-21 |
| Début de diffusion | 2026-04-21 |
| Analyse des réponses | 2026-04-27 |
| Guide d'entretien prêt | 2026-04-28 |
| Début du terrain | 2026-04-30 |
| Fin du terrain | 2026-05-06 |
| Analyse qualitative | 2026-05-08 |
| Rapport final | 2026-05-10 |
| Steering Committee | 2026-05-11 |

## Dispositif

- **Volet quantitatif** : questionnaire diffusé via Microsoft Forms,
  cible de 200 réponses
- **Volet qualitatif** : 8 entretiens semi-directifs, participants recrutés
  parmi les répondants ayant déclaré une friction et accepté d'être recontactés

## Critère de sélection des interviewés

Répondants combinant un score de clarté bas et un score de valeur élevé —
profil le plus susceptible d'expliquer l'écart entre intérêt et non-conversion.

## Livrable attendu

Rapport présenté au Steering Committee du 11 mai 2026, servant à arbitrer
la roadmap Q3 et le redesign de la page de tarification.

# Projets

Les études **en cours** vivent ici — celles qui ont une échéance et un
livrable attendu.

Une étude terminée est déplacée dans `05-Archives/`. Ce qu'elle a appris,
lui, reste dans `03-Connaissances/` : c'est ce qui distingue un projet
d'une connaissance.

**Aucune étude active pour l'instant.** Lance-en une avec `/go`.

> Ne confonds pas un projet et un domaine : « Refonte de la page tarifaire »
> est un projet (ça se termine), « Tarification » est un domaine (ça ne se
> termine jamais). Les domaines sont dans `02-Domaines/`.
